# Real model backends (Whisper-small, all-MiniLM-L6-v2 + FAISS, Qwen2.5-3B-Instruct).
# Install on top of requirements.txt. Versions below are the ones the
# evaluation report was produced with (Python 3.12.15, Windows 11,
# RTX 4060 Laptop 8 GB, NVIDIA driver 555.97).
#
# torch must come from the PyTorch CUDA index, so install it first:
#   pip install torch==2.4.1+cu124 --index-url https://download.pytorch.org/whl/cu124
# (CPU-only machines: torch==2.4.1 from PyPI works, just much slower.)
# Then:
#   pip install -r requirements-real.txt
#
# Also required on PATH: ffmpeg (tested with 7.1.1). Whisper uses it to decode
# uploads, and track_a/asr.py uses its ffprobe for the audio checks.
#
# Model weights are NOT downloaded by pip. Download them yourself once:
#   huggingface-cli download Qwen/Qwen2.5-3B-Instruct --revision aa8e72537993ba99e69dfaafa59ed015b17504d1
#   huggingface-cli download sentence-transformers/all-MiniLM-L6-v2 --revision 1110a243fdf4706b3f48f1d95db1a4f5529b4d41
#   Whisper-small (small.pt, ~460 MB) downloads on first use into ~/.cache/whisper.
